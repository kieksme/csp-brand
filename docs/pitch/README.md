# CSP Pitchdeck

`CSP-Pitchdeck-DE.pptx` enthält 14 bearbeitbare Folien im CSP-Branding mit Sprechernotizen und Quellen.

Für Kundengespräche: Folien 1–12, ungefähr zehn Minuten. Folie 13 ergänzt die interne Diskussion mit Kollegen. Folie 14 beantwortet technische Rückfragen.

Das Deck stellt das Open-Source-Produkt und das Projektangebot für Einrichtung, Integration und Übergabe vor. Die 80 % KI-Vorfilterung sind ausdrücklich ein Zielwert ohne eigene Messung. Direkter menschlicher Support, mögliche Fremdkosten und die Übergabe von Skills bleiben klar sichtbar.

Produktbaseline: CSP 0.13.4. Vor weiteren Kundenterminen Integrationsaussagen und Kontaktdaten bei Bedarf aktualisieren. Produktbilder zeigen synthetische Demo-Daten. CSP-Markenassets unterliegen den gesonderten Regeln in `BRAND-LICENSE.md`.
